
## 测试工具

> 暂停更新

测试器重点关注面板软件的基础功能在实机场景下的表现.

测试器设计为一个独立程序, 有两种运行模式:
1. 测试模式: 启动面板并开始整个测试流程
2. 辅助模式: 将自身作为面板的实例程序, 用于被面板启动并输出对应结果, 可通过启动参数指定不同测试用例

**直接运行**

直接运行时输出帮助内容:
```
## IpacPanel 测试工具

1. 将测试器和面板软件放置在同一目录
2. 使用 `--run-test` 启动测试

测试结果将生成在 `./tester.md` 文件.
```

使用 `--run-test` 启动时检查同目录下的面板软件并开始测试流程.

测试过程中以追加模式写文件 `./tester.md` 来记录测试结果.

使用 `- [x]` 表示测试通过, `- [ ]` 表示测试未通过.

---

在测试 实例启动 相关功能时, 测试器需要将自身复制到面板默认实例目录, 让面板来运行测试器的辅助模式以配合进行测试.

测试器需要通过修改面板配置或实例配置并重启守护进程和管理进程来实现测试.

---

## 测试内容

以下为测试内容, 选中状态表示对应测试代码已实现:

### 初始化

- [x] 首次启动正常: 启动后存在守护进程和管理进程
- [x] 生成默认配置和初始账号: 在正确位置生成对应 yml 文件, 内容不为空且可被 yml 解析
- [x] 相同路径下不可重复启动守护进程: 重复启动的守护进程自动退出

### 启动实例

- [x] 自动启动实例: 按照指定时间间隔启动实例
- [x] 自动启动优先级: 按照指定的优先级顺序启动实例

### 自动重启

- [x] 实例自然退出后等待指定的时间间隔重新启动实例
- [x] 实例异常退出后等待指定的时间间隔重新启动实例

### 计划任务

- [x] 计划任务按照正确的周期运行
- [x] 启动: 正确完成启动, 对于已启动的实例无反应, 与其他计划任务冲突时不会重复执行
- [x] 停止: 正确完成停止, 对于已停止的实例无反应, 与其他计划任务冲突时不会重复执行
- [x] 重启: 正确完成重启, 对于已启动的实例先停止再等待时间最后启动, 对于已停止的实例等待时间后启动, 与其他计划任务冲突时不会重复执行
- [x] 严格重启: 正确完成重启, 对于已启动的实例则进行重启, 对于已停止的实例则不进行重启
- [x] 命令: 正确发送键盘事件, 正确发送命令文本且被辅助程序接收

### 终端模式

- [ ] 无终端模式不处理终端输出: 启动无终端实例后不产生终端历史, 不广播终端输出
- [ ] 无终端模式不支持 WebSocket 终端: 连接 WebSocket 终端返回 409 或拒绝连接
- [ ] 无终端模式不支持发送命令: 通过 API 发送命令返回错误, 辅助程序不收到 stdin 数据
- [ ] 普通终端支持基本输入输出: 辅助程序收到 stdin 数据, 面板可读取 stdout 输出
- [ ] 仿真终端支持交互功能: 辅助程序可收到终端控制序列和 resize 事件

### 停止命令

- [ ] 默认 ^C 中断: 配置 `^C` 时发送 `0x03` 字节, 辅助程序收到 ctrl_c 事件
- [ ] 自定义停止命令: 配置自定义命令文本时发送命令并追加回车, 辅助程序收到对应 stdin 数据
- [ ] 无终端模式下停止命令无效: 配置停止命令但无终端实例不接收 stdin, 面板直接结束进程
- [ ] 空停止命令直接结束进程: 配置留空时面板直接 kill 进程, 不发送 stdin

### 实例控制

- [ ] 强制停止: kill 操作直接结束进程, 不发送停止命令, 不等待优雅退出
- [ ] 启动中取消: 实例启动过程中发起 stop, 取消启动并恢复停止状态
- [ ] 停止中强制停止: 实例停止过程中发起 kill, 立即强制结束
- [ ] 重复启动无副作用: 对已运行的实例再次 start 无变化, 不产生新进程
- [ ] 已删除实例拒绝操作: 删除中的实例拒绝 start/stop/restart 操作

### 实例管理

- [ ] 创建实例: 新实例写入 instances.yml, 面板可读取并显示
- [ ] 更新实例: 修改实例配置后 instances.yml 更新, 运行中的终端模式需重启生效
- [ ] 删除实例: 删除实例后 instances.yml 移除, 可选清理实例文件目录
- [ ] 实例分组: 实例可按分组过滤, 未分组实例归入默认分组

### 编码

- [ ] 输入编码: 配置非 UTF-8 输入编码后, 发送的命令文本被正确转换
- [ ] 输出编码: 配置非 UTF-8 输出编码后, 辅助程序 stdout 被正确解码

### 配置修正

- [ ] 非法终端模式自动修正为默认值: 配置 terminal=0 或 terminal=99 后 normalise 为 TERMINAL=2
- [ ] 实例名称包含特殊字符: 名称含 `\` `/` `:` `*` `?` `"` `<` `>` `|` 时被替换为 `_`
- [ ] 空路径自动填充默认值: 实例 path 留空时自动设为 `./instances/`
- [ ] 空编码自动填充默认值: 实例 input_encoding 或 output_encoding 留空时自动设为 utf-8
- [ ] 空网页标题自动填充默认值: WebTitle 留空时自动设为 `IpacPanel`
- [ ] 空监听地址自动填充默认值: Listen 留空时自动设为 `127.0.0.1:25555`
- [ ] 负数历史大小自动修正为默认值: HistorySize < 0 时自动设为 27
- [ ] 负数自启动间隔自动修正为默认值: AutoStartInterval < 0 时自动设为 200
- [ ] 负数自动重启间隔自动修正为默认值: AutoRestartInterval < 0 时自动设为 1000
- [ ] 非正数 SSE 保活时长自动修正为默认值: SSEKeepalive <= 0 时自动设为 15000
- [ ] 重复实例名称自动追加序号: 两个实例同名时第二个自动追加 `-2` 后缀
- [ ] 重复用户名自动追加序号: 两个用户同名时第二个自动追加 `-2` 后缀
- [ ] 分组名称 UNGROUPED 自动修正为空: 设置分组为 UNGROUPED 时自动转为未分组
- [ ] 前后空格自动去除: 实例名称/路径/命令/停止命令的前后空格被自动 trim
- [ ] 负数启动优先级被拒绝: 实例 start_priority < 0 时面板拒绝创建
- [ ] 负数重启延迟被拒绝: 实例 restart_interval < 0 时面板拒绝创建
- [ ] 无效编码被拒绝: 实例 input_encoding 或 output_encoding 设为无效值(如 gb2312)时面板拒绝创建
- [ ] 路径超长被拒绝: 实例 path 超过 2048 个字符时面板拒绝创建
- [ ] 命令超长被拒绝: 实例 command 超过 4096 个字符时面板拒绝创建
- [ ] 停止命令超长被拒绝: 实例 stop_command 超过 4096 个字符时面板拒绝创建
- [ ] 计划任务无效操作被拒绝: 任务 action 设为非 start/stop/restart/command 时拒绝
- [ ] 计划任务无效表达式被拒绝: 任务 expr 不是合法的 Cron 表达式时拒绝

### 自启动

- [ ] 相同优先级按名称排序: 优先级相同的实例按名称升序启动
- [ ] 自启动间隔不为零: 实例启动之间有指定的延迟间隔
- [ ] 非自动启动实例被跳过: 未设置 auto_start 的实例不被启动
