## Code

**守护进程**

如果更改了守护进程与管理进程之间的通讯部分:
- 更新 `./daemon/version/version.go` 文件中的 `DaemonProtocol` 值

**管理进程**

常规更新:
- 更新 `./daemon/version/version.go` 文件中的 `Version` 版本号

数据迁移:
- 更新 `./daemon/version/version.go` 文件中的 `ControllerDataVersion` 值

**前端**

已通过 `${IpacPanelVersion}` 占位符由管理进程动态注入版本号, 无需手动更新.

## GitHub

提交并推送所有更改.

查看代码中的 `./daemon/version/version.go` > `Version` 版本号.

运行:
```
git tag ${Version}
git push origin ${Version}
```

GitHub Actions 会自动运行构建并发布.

完成后需要手动进入 [发布页面](https://github.com/ApliNi/IpacPanel/releases) 修改发布信息和标签.

## 删除 Tag

删除本地 Tag:
```
git tag -d ${Version}
```

删除本地和远程 Tag:
```
git tag -d ${Version}
git push origin --delete ${Version}
```
