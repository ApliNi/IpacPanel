# 输入约束

本文档描述前端输入与后端接口的统一约束。除特别说明外, 文本长度按 Unicode 字符数计算; 文件内容大小按 UTF-8 字节数计算。前端优先使用 HTML 属性硬限制, 复杂多行输入在失去焦点和保存时静默规范化, 后端始终做最终约束。

## 通用策略

- 普通单行文本: 输入时通过 `maxlength` 限制, 保存时再次截断或后端校验。
- 数值输入: 输入时通过 `min` / `max` 提示范围, 保存时静默调整到最近值, 后端再次调整或校验。
- 多行文本: 输入时尽量使用 `maxlength`; 对于需要按行去重/限行的输入, 失去焦点和保存时静默规范化。
- 新建文件初始内容和文件编辑器内容不做静默截断; 保存时按 9 MiB 阈值自动选择 JSON 或并发分片上传通道。
- 特殊字符: 前端对明确禁止的特殊字符通知, 后端再次校验。
- 后端约束失败: 返回 API 错误并由前端通知。
