
## 无终端

允许某些实例程序在运行时省略终端功能来提高性能.

在实例高级配置中的 PTY 模式选项之前添加一个 Terminal 选项, 默认开启, 关闭后, 守护进程运行此实例完全无需监听终端内容, 不向管理进程发送终端消息, 不支持输入功能, 做最大程度的性能优化 (如果正在运行则推迟到下次启动时应用)

前端判断如果当前实例的运行模式为无终端, 则隐藏前端 terminal-wrapper 组件, 可同时省略终端初始化代码.
- 需要对实例运行时修改模式做处理, 修改后始终推迟到实例下次启动前应用, 避免修改后无法查看正在运行实例的终端.

**要求**

无终端模式应该作为与普通模式和 PTY 模式平等的第三个模式, 需要做独立的实现而非在普通终端模式上屏蔽已监听的内容. 允许进行代码上的复用但要确保设计上独立.

**重构**

将终端模式重构为数值枚举三种模式:
- NO_TERMINAL=1 无终端
- TERMINAL=2 普通终端 (默认值)
- PTY_TERMINAL=3 仿真终端

移除实例配置的 `use_pty: true/false`, 改为 `terminal: 1/2/3`.
- 如果配置为无效值则修正为默认值

同时重构 HTTP API / 守护进程与管理进程通讯 / 相关函数 使用的模式字段, 代码中使用枚举而非硬编码数值.
