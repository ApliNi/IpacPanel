
## 更新

1. 从 [Releases](https://github.com/ApliNi/IpacPanel/releases) 下载对应架构的软件包 `.zip` 文件
2. 使用管理员账户打开面板
3. 点击 `SETTINGS` 按钮, 点击 `UPDATE` 页面
4. 上传下载的软件包 `.zip` 文件
5. 点击卡片右下角 `UPDATE` 按钮, 点击弹窗中的 `UPDATE` 按钮
6. 等待面板自动更新

完成后管理进程将自动重启, 已运行的实例会保持运行.

## 更新失败

**更新压缩包无效**
- 出现场景: 上传完成后, 后端无法从 zip 中提取有效管理进程二进制
- 常见原因: 压缩包损坏, 上传不完整, 压缩包结构不符合发布格式, 包内缺少目标二进制, 或服务端读取/提取压缩包失败
- 解决方案: 重新下载发布包, 不要手动重新打包, 确认文件完整

**发布压缩包中的管理进程二进制无效**
- 出现场景: 包内存在管理进程二进制, 但后端校验不通过
- 常见原因: 上传了错误角色的程序, 版本信息无法解析, 守护进程协议不兼容, 或二进制不适用于当前平台
- 解决方案: 确认下载的是当前系统和架构对应的官方发布 `.zip` 包

**创建更新目录失败**
- 出现场景: 初始化上传时, 后端创建更新目录失败
- 常见原因: 磁盘权限不足, 目录被占用, 磁盘空间不足, 路径异常
- 解决方案: 检查控制器数据目录权限和磁盘空间后重试

**提交更新文件失败**
- 出现场景: 上传和校验通过后, 后端提交待应用更新文件失败
- 常见原因: 临时文件移动失败, 更新目录权限不足, 磁盘异常, 安全软件拦截
- 解决方案: 检查更新目录权限和磁盘空间, 确认没有安全软件拦截文件操作

**没有待应用的更新文件**
- 出现场景: 点击 `UPDATE` 应用更新时, 后端找不到待应用更新文件
- 常见原因: 尚未上传成功, 待应用文件被删除, 更新目录被清理
- 解决方案: 重新上传更新包后再点击 `UPDATE`

**更新文件无效**
- 出现场景: 应用更新前, 后端校验待应用二进制失败
- 常见原因: 待应用文件损坏, 上传文件不完整, 二进制版本信息异常
- 解决方案: 重新上传官方发布包后再应用更新

**重启管理进程失败**
- 出现场景: 应用更新时, 后端请求守护进程重启管理进程失败
- 常见原因: 守护进程不可用, 权限不足, 进程管理异常
- 解决方案: 检查守护进程状态和服务端日志, 确认管理进程由守护进程管理
