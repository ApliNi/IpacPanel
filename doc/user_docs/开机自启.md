

以下示例假设面板软件放置在 `/IpacPanel` 目录下, 使用 `UserName` 用户. 使用时请根据实际进行修改.

## Linux

### systemd (未测试)

在 `/etc/systemd/system/` 目录下创建 `ipac_panel.service` 文件:
```
[Unit]
Description=IpacPanel

[Service]
Type=simple
User=UserName
ExecStart=/IpacPanel/IpacPanel
Restart=always

[Install]
WantedBy=multi-user.target
```

### BusyBox

在 `/etc/rc.local` 中添加以下内容:
```
ipac_panel::respawn:/IpacPanel/IpacPanel
```


## Windows

### "启动" 目录

1.为面板管理进程创建快捷方式
2. 将快捷方式文件复制到 `C:\Users\UserName\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup` 目录中

### 计划任务

1. 启动 `taskschd.msc` [任务计划程序]
2. 在右侧 `操作` 区域点击 `创建任务`
3. 名称填写 `ipac_panel`
4. 按需选择 `不管用户是否登录都要运行`
5. 点击 `触发器` 标签, 点击 `新建`
6. 将 `开始任务` 设置为 `启动时` 或 `登录时`
7. 按需选择延迟任务时间
8. 点点击 `确定`
9. 点击 `操作` 标签, 点击 `新建`
10. 在 `程序/脚本` 部分点击浏览, 选择面板守护进程
11. 点击 `确定`
12. 点击 `设置` 标签, 取消勾选:
	- `如果任务运行时间超过以下时间，停止任务`
	- `如果请求后任务还在运行，强行将其停止`
13. 点击 `确定`
