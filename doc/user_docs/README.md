
## 安装

面板无需安装到系统程序目录, 运行时不会对系统目录造成污染.

1. 从 [GitHub 发布](https://github.com/ApliNi/IpacPanel/releases) 下载对应系统和架构的版本
2. 解压到任意目录, 比如 `/home/user/IpacPanel` 或 `C:\Users\user\IpacPanel`
3. 运行 `IpacPanel` 或 `IpacPanel.exe` 启动面板

Linux 下可能需要手动设置执行权限:
- 给整个目录添加可执行权限: `chmod -R +x /home/user/IpacPanel`
- 给面板程序添加可执行权限: `chmod +x ./IpacPanel && chmod +x ./IpacPanel_Controller`.


## 初始化

首次运行时控制台会显示一次初始用户名和密码.
- 可以进入网页使用用户菜单修改
- 或通过配置文件 `./data/auth.yml` 直接修改 `pass` 字段, 重启面板后会自动生效并替换为密码哈希值

**远程连接**

面板默认监听 `127.0.0.1:25555`, 如果需要远程访问, 请通过网页设置或配置文件 `./data/config.yml` 将其修改为 `0.0.0.0:25555`.
- 重启面板管理进程后可生效
- Windows 下可能会出现防火墙提示, 需要选择允许放行

**重启**

部分设置需要重启面板管理进程才能生效.
- 网页使用 `SETTINGS > DEBUG > RESTART CONTROLLER`
- 本地使用 `pkill IpacPanel_Controller` [`IpacPanel` 会自动重启 `IpacPanel_Controller`]
- 也可手动重启 `IpacPanel` 进程, 但会同时关闭正在运行的实例


## 实例

面板可用于代替 CMD 等桌面终端来运行程序, 每一个程序被称为一个 **实例**.

**创建/编辑实例**

在网页中点击 `NEW` 开始创建第一个实例.
- `NAME` 为实例名称, 要求具有唯一性
- `PATH` 为实例的运行路径或程序所在目录, 支持相对路径或绝对路径
- `START COMMAND` 为实例程序的启动命令, 可以为实例程序文件名及其启动参数, 可以使用其他路径下的程序. 如果为空则会启动终端程序
- `AUTO START` 选项可控制在面板启动后是否自动启动这个实例. `Priority` 表示这个实例在面板中被启动的顺序, 数值越大越先启动, 数值相同则按照实例名称升序排序启动
- `AUTO RESTART` 选项用于当实例程序自行退出后是否自动重启程序. `Interval` 表示在重启前等待多长时间, 单位为毫秒
- `GROUP` 可为实例设置分组, 分组将在实例列表中体现, 便于管理

**高级选项**

在创建实例或编辑实例卡片中, 可以点击 `ADVANCED` 切换到高级选项设置.

`TERMINAL` 为终端模式选择:
- `NO_TERMINAL` 无终端: 仅程序, 不处理程序的终端输出
- `TERMINAL` 普通终端 [默认]: 支持基本终端输入输出, 无法进行终端实时交互
- `PTY_TERMINAL` 仿真终端: 支持部分交互功能, 可用于支持 vim, tmux 等终端交互程序

仿真终端相对普通终端可能会消耗更多 CPU 资源, 对于没有交互需求的实例应该使用普通终端模式.
- 如果需要调整实例程序的输出内容尺寸可通过环境变量来实现, 如 `COLUMNS=50`, `LINES=24`

`STOP COMMAND` 可设置停止实例使用的方法, 默认使用 `^C` 中断, 支持使用发送自定义命令, 对于无终端模式此功能无效.
- 对于大多数程序来说, 此设置无需修改

`CLEANUP COMMAND` 如果设置, 将在实例正常停止后运行, 用于运行清理脚本等操作.
- 对于 KILL 停止实例时, 不会运行此命令. 同时 KILL 也会强制停止正在运行的清理命令.

`INPUT ENCODING` 与 `OUTPUT ENCODING` 用于控制终端输入输出文本的编码格式, 如果终端出现乱码则需要修改.
- 切换不同终端模式可能导致编码发生变化
- 通常仿真终端模式能够更好的自动匹配编码

`ACCESS LINKS` 访问链接是用于在实例卡片中快速打开地址或复制文本的功能.
- 内容一行一个, 支持使用 `#` 注释
- 格式支持: `名称: 内容` [复制内容], `名称: 网址` [打开网址], `网址` [打开网址]

**计划任务**

每个实例中可以运行独立的计划任务, 需要使用 [Cron/Quartz 表达式](https://zh.wikipedia.org/zh-cn/Cron) 来定义触发时间.
- 在此页面点击 `HELP` 按钮可查看表达式功能说明和示例
- 每个实例支持添加多个计划任务
- 点击 [ON] 按钮可切换此计划任务是否启用

计划任务动作:
- `START` 启动, 如果实例处于停止状态则启动
- `STOP` 停止, 如果实例处于运行状态则停止
	- `USE KILL STOP` 使用 KILL 方式停止实例
- `RESTART` 重启, 先停止实例再启动实例
	- `USE KILL STOP` 使用 KILL 方式停止实例
	- `STRICT RESTART` 如果实例处于运行状态则重启, 如果处于停止状态则不启动
- `COMMAND` 发送键盘事件或自定义命令

**删除实例**

默认情况删除实例功能会将实例配置从面板中删除, 无法恢复.

如果选择同时删除实例文件, 面板会尝试原子删除实例, 如果失败则会还原实例文件并提示删除失败, 且不会删除实例配置.


## 终端

终端页面用于查看实例输出, 向实例发送输入, 并控制实例运行状态.

终端输出中可能包含面板生成的系统消息, 用于提示启动失败, 计划任务执行结果等信息.

**实例控制**

终端顶部会显示当前实例名称和运行状态.
- `START` 启动实例
- `STOP` 正常停止实例
- `RESTART` 重启实例
- `KILL` 强制结束实例, 通常仅在实例无法正常停止时使用
- `CONFIG` 打开实例配置

如果实例配置为 `NO_TERMINAL` 无终端模式, 终端区域不会连接实例输入输出, 仅可使用实例控制按钮.

**终端输入输出**

普通终端模式支持基本输入输出, 仿真终端模式支持更多实时交互功能.
- 如果需要使用 vim, tmux 等交互式程序, 应在实例高级选项中选择 `PTY_TERMINAL`
- 如果终端出现乱码, 可以在实例高级选项中调整输入输出编码
- 如果需要固定终端显示尺寸, 可以通过环境变量设置, 如 `COLUMNS=50`, `LINES=24`

终端连接断开后会自动尝试重连, 页面切换或关闭后只会断开终端连接, 不会停止实例.

**快捷键**

- `Ctrl+C`: 选中文本时复制终端内容, 未选中文本时确认后发送中断
- `Ctrl+V`: 向终端粘贴文本
- `Alt + 鼠标滚轮`: 快速滚动
- `Alt + 左键单击`: 将光标移动到此处
- `右键单击`: 选择单词
- `左键双击`: 选择单词
- `左键三击`: 选择行


## 文件管理

文件管理位于终端页面下方, 默认以实例运行路径作为根目录.

**浏览文件**

文件列表会显示当前目录下的文件和目录, 支持分页显示.
- 点击目录可进入目录
- 点击路径段可跳转到对应目录
- `REFRESH` 可重新加载当前目录
- 搜索框可搜索当前目录, 输入包含路径分隔符的路径时可跳转

面板会记住每个实例最后访问的目录, 再次打开实例时会自动回到上次位置.

**创建和上传**

点击 `CREATE` 可创建文件, 创建目录或上传文件.
- `NEW FILE` 创建文件, 可填写初始内容
- `NEW DIR` 创建目录
- `UPLOAD` 上传文件, 支持文件和文件夹混合上传

上传支持分片处理和进度显示, 大文件或多个文件上传时可在上传列表中查看状态.

**文件操作**

点击文件可根据文件类型打开对应功能.
- 文本文件会使用编辑器打开, 支持语法高亮和保存
- 图片, 视频, 音频文件会打开预览
- 其他文件可通过文件操作弹窗下载或查看信息

文件操作弹窗支持查看文件信息, 重命名, 下载, 删除和解压支持的压缩包.
- 删除目录时会递归删除目录内容
- 解压支持选择解压位置, 并显示执行进度

**批量操作**

点击文件列表左侧按钮可进入选择模式, 选择多个文件后可进行批量操作.
- `COPY` 批量复制文件或目录
- `MOVE` 批量移动文件或目录
- `DELETE` 批量删除文件或目录

批量操作支持包含/排除规则, 可用于限定实际处理的文件或目录.


## 仪表板

仪表板可自动采集系统和面板在运行过程中的性能指标, 采集精度为 1 秒.

**存储模式**

仪表板默认使用内存存储数据, 在管理进程重启后数据会丢失.
- 内存存储模式不推荐调高数据保留时间

SQLite 存储模式支持长期存储, 可用于存储长达数月或数年的指标数据, 并且支持自动降采样存储.
- 最大保存天数配置用于自动删除超过指定天数的数据
- 最大压缩天数配置用于自动降低超过指定天数的数据精度以减少存储空间占用, 目标精度为 10 秒

**图表页面**

仪表板页面支持选择查看最近指定时长 (分钟) 的数据, 支持切换查看不同硬件 (磁盘或网卡) 的数据.

仪表板会根据窗口尺寸和选择查看时长自动调整加载数据精度以保证性能和显示效果.


## 设置

设置页面包含 `CONFIG`, `UPDATE`, `DEBUG` 三个主页面, 其中 `CONFIG` 下分为 `OPTIONS`, `METRICS`, `WEB`, `POW`.

具体配置文件字段, 默认值和注释请参考 [配置文件](./data_config.yml.md).

**基础设置**

`CONFIG > OPTIONS` 可修改面板基础行为, 如网页标题, 监听地址, 终端历史大小, 自动启动间隔和实例更新目录等.
- 部分设置需要重启面板管理进程后生效
- 远程访问通常需要将监听地址设置为 `0.0.0.0:25555`

**仪表板设置**

`CONFIG > METRICS` 可控制仪表板指标采集, 公开访问和存储方式.
- 公开仪表板允许未登录用户以普通用户权限访问仪表板
- 存储模式和数据保留策略可结合仪表板章节选择

**在线更新**

`UPDATE` 可上传对应平台和架构的发布 zip 包并应用管理进程更新.
- 发布包名称通常为 `IpacPanel-[platform]-[architecture].zip`
- 应用更新会触发管理进程重启, 更新会在重启时完成
- 更新前建议备份面板目录或至少备份 `./data/`

**调试**

`DEBUG` 可开启调试日志或重启管理进程.
- 调试日志通常仅在排查问题时开启
- 重启管理进程不会主动停止正在运行的实例

### HTTPS/反向代理

`CONFIG > WEB` 可配置面板 HTTPS.
- 启用 HTTPS 时需要填写服务器可读取的证书文件和私钥文件路径
- 强制 HTTPS 会将 HTTP 请求重定向到 HTTPS

如果使用 Nginx, Caddy 等反向代理提供 HTTPS, 面板自身通常无需启用 HTTPS.
- 反向代理后方需要正确设置可信代理 IP, 否则客户端 IP 和安全相关判断可能不准确
- 开放公网前建议确认代理只转发必要端口, 并使用强密码

### POW

POW 用于提高登录等敏感请求的提交成本, 降低暴力请求影响.
- 启用后登录可能需要等待浏览器完成计算
- 任务数量和难度越高, 浏览器计算时间越长
- 客户端和服务器时间偏差过大可能导致验证失败

如果用户设备性能较弱或网络环境复杂, 不建议设置过高难度.


## 多用户

用户页面可管理当前账号和多用户配置.
- 当前用户可修改用户名和密码
- `RESET TOKEN` 可重置当前用户登录令牌, 当前会话需要重新登录
- `LOGOUT` 用于退出登录

授权文件字段和手动修改方式请参考 [授权文件](./data_auth.yml.md).

管理员可创建, 编辑和删除用户.
- 可为用户设置管理员, 普通用户或禁用权限
- 可限制用户允许访问的实例和分组
- 删除用户不会删除实例和文件

### 权限

权限用于限制用户可看到和可操作的面板功能, 实例和分组.
- 授权范围会影响用户在实例列表, 终端, 文件管理等页面中可访问的内容
- 分组授权适合批量管理同一类实例
- 实例授权适合为用户开放少量指定实例

多用户功能不能做到系统级隔离.
- 同一面板内的实例仍运行在同一个系统环境中
- 不要把不可信用户放在同一面板内
- 如果需要更强隔离, 应使用独立系统用户, 容器或单独部署面板



## 最佳实践

**安全性**

目前此面板的安全性尚未得到充分测试和验证, 请谨慎将其开放到公网.
- 建议设置高安全系数密码
- 推荐使用 Tailscale 等异地组网工具连接

不推荐使用管理员权限运行面板, 如果需要, 请确保实例程序可信.

注意: 本项目大量使用 AI 工具进行开发.

**多用户**

此面板的多用户功能无法做到完全隔离, 您可能需要进行系统层面额外的权限设置.

**服务提供商**

面板本身的资源占用较低, 为保证安全性, 推荐为每个用户/主机安装单独的面板程序, 避免多个用户使用同一个面板.


## 细节和特性

**运行实例**
- Windows: 通过 CreateProcess / ConPTY 运行实例, 默认不使用 shell, 仅在实例为 `.cmd` 或 `.bat` 脚本时, 使用 `cmd.exe` 作为脚本解释器
- Linux: 通过 fork + execve / PTY 运行实例, 默认不使用 shell

**启动优先级**

优先级数值越大的实例越早启动, 启动后不会等待实例启动完成, 而是按照设置的间隔时间继续启动其他实例.
- 优先级相同的实例按照实例名称升序排序启动
- 优先级支持使用负数

**实例更新**

面板会在实例启动时先检查更新目录, 如果存在文件则覆盖到实例目录, 同时备份覆盖目标作为备份, 覆盖失败时尽量进行回滚, 最后正常启动实例程序.
- 回滚发生错误不会影响实例继续启动, 启动失败不会进行回滚
- 更新功能会合并目录, 而非替换目录
- 仅备份实例目录与更新目录的文件交集, 默认不会备份完整实例

**终端**
- `Ctrl + C`: 在选中文本时默认复制选中文本, 未选中时会提示是否发送终止信号
- 可直接输入内容, 回车后发送到实例程序, 对于仿真终端模式支持键盘交互

**文件列表**
- 点击路径: 转到指定路径
- 点击文件图标: 多选文件/目录, 支持在多个目录中多选文件
- 点击文件列表图标: 全选当前显示的文件/目录, 支持搜索模式选择
- 点击对象: 编辑/预览, 对于不支持预览的文件则会打开操作卡片
- 右键未选择对象: 打开操作卡片
- 右键已选择对象: 打开批量操作卡片
- 搜索: 如果当前目录没有分页, 则前端搜索, 否则后端搜索; 不支持深度搜索
- 转到路径: 搜索框输入路径回车后自动跳转, 支持相对路径和绝对路径

**文件上传**

前端会自动处理文件上传的分片和错误恢复, 已完成的项目会自动从上传列表移除, 出现错误的项目会显示错误信息.

拖拽上传支持同时添加文件和文件夹. 文件会直接加入上传列表, 文件夹会先扫描再加入其中的文件.

由于浏览器文件选择器限制, 点击选择文件和点击选择文件夹仍由不同入口触发, 不承诺在同一个系统选择窗口中混选文件和文件夹.

**前端资源**

如果启动时存在 `./public` 目录, 则会优先读取该目录下的静态资源, 如果不存在则会回退到内置资源.

**免安装**

面板无需安装到系统程序目录, 运行时不会对系统目录造成污染.

**配置和存储**

```
.
├── data/					# 面板数据
│   ├── dashboard/			# 仪表板数据
│   ├── update/				# 管理进程更新目录
│   ├── auth.yml			# 用户和权限配置
│   ├── config.yml			# 面板配置
│   ├── instances.yml		# 实例配置
│   └── temp.yml			# 临时文件
│
└── instances/				# 默认实例文件目录
```

- `./data/auth.yml`
	- 用户和权限配置, 文件格式请参考 [授权文件](./data_auth.yml.md)

- `./data/config.yml`
	- 面板配置, 文件格式请参考 [配置文件](./data_config.yml.md)

- `./data/instances.yml`
	- 实例配置, 文件格式请参考 [实例配置文件](./data_instances.yml.md)

- `./data/temp.yml`
	- 用于支持断电后的数据清理, 比如原子操作文件残留

**手动回滚/重启**

如果更新后发现面板前端无法访问, 那么面板支持通过不停机手动更新来解决问题.

1. [可选] 将新的管理进程可执行文件放置在 `./data/update/` 目录或手动修改配置文件
2. 强制结束 `IpacPanel_Controller` 进程
3. 守护进程会自动更新并重启管理进程


## 卸载

面板数据仅存储在运行目录中, 停止守护进程后删除面板根目录即可.
- 如果需要, 请注意备份数据: `./data/`
