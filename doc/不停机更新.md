## 不停机更新

不停机更新主要是保证用户的实例不会随面板更新而需要重启.

因此需要将面板分为两个部分, 其中守护进程部分承担了实例保活工作, 管理进程部分则承担了面板其他所有功能.

### 如何实现

我们需要将软件架构拆成两个部分, 守护进程和管理进程.
- 守护进程: 负责启动管理进程
- 管理进程: 负责面板所有功能, 并通过守护进程来运行实例应用

守护进程需要保持最少的功能, 简洁可靠的 API, 优秀的性能, 能够支持软件的不停机更新.

管理进程不可单独启动, 必须由守护进程来启动才能正确工作.

```
Browser
  -> 管理进程
      - Web UI
      - API
      - Auth
      - 配置
      - 自动重启
      - 定时任务
      - 输出展示
      - 浏览器 WebSocket
      - 可选: 输出历史缓存
      - IPC client
        -> 守护进程
            - 启动实例
            - 停止实例
            - 强杀实例
            - 持有 PTY/pipe
            - 写入 stdin
            - 读取 stdout/stderr/PTY
            - 如果管理进程在线, 实时推送输出
            - 如果管理进程不在线, 直接丢弃输出
```

### 守护进程

运行流程如下:
0. 用户启动软件 (守护进程)
1. 启动管理进程
2. 与管理进程进行通讯

守护进程仅做最少的功能, 其他功能 (如定时任务) 由管理进程提供.

守护进程只负责持有实例进程和终端 IO. 实例输出只在管理进程在线时实时转发, 管理进程重启期间的输出直接丢弃, 不缓存, 不补发.

### 管理进程

管理进程提供面板所有功能, 但不同的是, 管理进程需要通过守护进程来运行实例, 相当于使用守护进程代替现在的 PTY.

管理进程不再负责运行实例和处理 PTY.

### 通讯方式

守护进程与管理进程之间使用进程间通讯, 底层通讯方式, 避免额外的性能开销.

守护进程需要透传管理进程的日志消息到控制台.

通讯需要保证非阻塞, 不能因为实例过多日志过多而阻塞消息.

### 编译/发布

需要编译两个文件:

```
IpacPanel-<平台>-<架构>.zip:	// 以压缩包方式发布
	IpacPanel_Controller.exe	// 管理进程
	IpacPanel.exe				// 守护进程
```

管理进程不可单独启动, 必须由守护进程通过命令行参数的方式启动.

目标目录结构:
```
build		// 编译输出
data		// 面板数据
doc			// 文档
instances	// 默认实例

public		// 前端代码
controller	// 管理进程代码
daemon		// 守护进程代码

build.go	// 构建脚本
```

### 更新方式

通过管理进程的 web 接口来实现更新, 在实例列表的 .section-header 中添加一个设置按钮, 其中弹窗包含更新页面, 现阶段实现手动上传更新.

要求手动上传 IpacPanel 发布压缩包 (内含管理进程与守护进程二进制).

上传的文件暂存在 ./data/temp/ 中每个任务独立的临时文件夹里, 上传过程中使用分片上传方式, 与实例的文件上传方式一致.

管理进程校验压缩包中的二进制后自行完成替换: 先将当前可执行文件重命名为 *.old 备份 (已有备份则直接覆盖), 再原子覆盖自身, 最后管理进程自动退出, 由守护进程重启加载新版本. 守护进程不需要为更新单独实现接口, 仅在收到管理进程的更新退出通知后跳过等待延时立即重启.

管理进程每次成功启动后会清空 ./data/temp/ 目录, 并尽力删除程序目录中遗留的 *.old 备份文件.

**替换模式**

上传时可勾选"以替换方式更新", 校验压缩包内二进制的角色 (管理进程=controller, 守护进程=daemon) 后直接替换本机程序文件, 不校验守护进程协议, 不重启管理进程, 重启服务器后生效; 替换过程不会自动回滚.

### 版本检查命令

版本检查命令应该使用 YAML 格式返回版本内容:

```
$ IpacPanel_Controller.exe --version

version:
  role: controller
  version: 1.2.3
  daemon_protocol: 1

$ IpacPanel.exe --version

version:
  role: daemon
  version: 1.2.3
  daemon_protocol: 1
```
